# processkit v1.0.0-alpha.5

This prerelease completes the four engineering follow-ups extracted from the
v1.x implementation review in issue #135.

## Highlights

- Trusted native binaries for x86_64 and arm64 Linux and macOS, built and
  smoke-tested on maintainer-controlled target hosts with source and local-host
  provenance.
- A canonical Ed25519 public key and fail-closed exact-version bootstrap.
- Replay-safe mixed-root migration for supported v0.27.1 and v0.28.4 projects,
  with ownership baselines and direct CLI/aibox parity tests.
- Generated CLI and release facts plus a documented, tested public Rust API.
- Universal hash-locked Python runtime dependencies and stable local,
  container, and host-only diagnostic signals.

The v1.x line remains an exact-pin prerelease. The v0.x line remains the
default supported release.

## Verification

Each native binary has a checksum sidecar and provenance JSON. The signed
release envelope binds all four binary digests, the content archive, release
descriptor, and shipped provenance. Installation verifies the canonical key
fingerprint, envelope signature, checksum, size, and signed digest before the
binary is installed.

Fixes #165, #167, #168, and #170.
