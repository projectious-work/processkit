# Code of Conduct

## Our pledge

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In summary: be respectful, be constructive, and help make this a welcoming
space for everyone, regardless of background or experience level.

processkit is a process layer for AI-assisted work, which means a lot of what
gets discussed here is about how people and agents should collaborate. Those
are opinionated questions with more than one defensible answer. "I think this
is wrong because…" is a contribution, not an attack — please extend the same
assumption of good faith to others.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing others'
private information, and sustained disruption are not tolerated. The full
definitions are in the Contributor Covenant text linked above.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages — and anywhere someone is representing the project.

## Enforcement

Report concerns to **info@projectious.work**. Reports are handled privately.
The maintainers may edit, hide, or delete contributions, and may block accounts
from the repository, in response to behaviour that breaches this policy.

Because this is a small project, there is no separate enforcement committee.
If your report concerns a maintainer, say so and it will be handled with that
in mind.
