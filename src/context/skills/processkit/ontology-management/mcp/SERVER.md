# Ontology Management MCP

Schema-driven fallback tools for completed v1 ontology concepts. Dedicated
domain servers take precedence where domain-specific behavior exists.

| Tool | Purpose |
|---|---|
| `create_ontology_entity` | Create an explicitly identified validated entity |
| `get_ontology_entity` | Read one entity |
| `update_ontology_entity` | Update non-state fields |
| `transition_ontology_entity` | Enforce the declared state machine |
| `list_ontology_entities` | Query indexed entities by kind |
